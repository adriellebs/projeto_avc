# Origem dos dados

Os dados utilizados neste projeto foram obtidos a partir do dataset público
"Stroke Prediction Dataset", disponível no Kaggle:

- Link: https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset

A coluna `stroke` indica se o paciente já teve um episódio de AVC (1) ou não (0),
e as demais colunas representam fatores demográficos e clínicos (idade, gênero,
hipertensão, doença cardíaca, IMC, etc.).

Neste repositório é disponibilizada uma cópia do arquivo com as alterações 
realizadas nos nomes das colunas da tabela, onde foi feita a tradução para
português.
